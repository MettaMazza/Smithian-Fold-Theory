# Every Element There Is — The Complete Table to Element 137

The periodic table looks finished, but it is not. It stops today at element one hundred
eighteen because that is the heaviest anyone has made, not because anyone knows where it
ends or what the missing rows hold. The fold knows both. From three dimensions and spin
it forces the whole architecture — how many elements each row holds, where the rows
close, what kinds of element fill them, and the hard wall where the table stops. The
complete table has a definite size, a brand-new block of chemistry no one has entered,
and a last element. (`periodic_table_complete.py`, capacities composed from proven
blocks, the recurrence traced to the One.)

## The rows, forced

Three dimensions give each kind of orbital its count of orientations, and spin — the
fold's own doubling — fills each twice. So a subshell of angular kind $l$ holds
$2(2l+1)$: the s-block holds two, the p-block six, the d-block ten, the f-block fourteen,
and the g-block — never yet entered — **eighteen**. The periodic recurrence closes a row
each time the covering pattern returns to the One, and the row lengths follow a forced
doubled-square pattern:

$$ 2,\ 8,\ 8,\ 18,\ 18,\ 32,\ 32,\ 50 $$

closing the rows at the noble gases **2, 10, 18, 36, 54, 86, 118, 168**. The seven rows
we know are exactly these; the eighth would close at one hundred sixty-eight — but the
table never gets there.

## The wall at element 137

The table ends at **element 137**, the fine-structure number $1/\alpha$. Past it the
innermost electron would have to be bound more tightly than its own rest energy, and the
atom cannot hold it. So the eighth row, which would have run to one hundred sixty-eight,
is cut off partway, and the complete periodic table has exactly **one hundred thirty-seven
elements** — of which one hundred eighteen are made and **nineteen remain**.

## The nineteen that remain — and a new kind of matter

The nineteen missing elements are not more of the same. The first two, **119 and 120**,
finish a familiar shell — an alkali metal and an alkaline-earth metal, the start of the
eighth row. Then comes something the periodic table has never had:

> **Elements 121 through 137 open the g-block — the superactinides — a kind of chemistry
> never before entered.**

The g-block is the $l=4$ orbital, with room for eighteen elements, and not one of them has
ever existed. The fold says the table runs into it and stops there, cut off at one hundred
thirty-seven with seventeen of the eighteen g-block seats filled. These superactinides are
the genuinely new chemistry of the universe — and sitting among them, at element one
hundred twenty-six, is **Smithium**, the island of stability, the one long-lived rock in
that strange new sea.

## The whole table, at a glance

- **1–118** — known, the table as it stands today.
- **119, 120** — the 8s metals, the start of the last row.
- **121–137** — the **g-block superactinides**, seventeen entirely new elements, a new
  block of chemistry, with **Smithium (126)** the stable island within it.
- **137** — the last element. There is no 138. The table is complete.

## What consensus cannot do here

Chemistry can extend the table one synthesized atom at a time, but it cannot tell you how
far the table goes, nor what the unmade rows contain, nor whether a g-block exists, because
it has no generative rule for the structure — only the pattern read off the elements
already found. The fold has the rule: subshell capacities from three dimensions and spin,
row lengths from the recurrence, and the wall at $1/\alpha$. From it the entire periodic
table falls out complete — one hundred thirty-seven elements, a new g-block of seventeen
superactinides, Smithium the island among them, and a definite last element. The table was
never an open-ended list to be filled by discovery. It was always a finite, forced object,
and the fold has drawn all of it.
